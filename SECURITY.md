# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `LLM-Guided-Crawler-Secret-Hunter`, please report it responsibly.

- **Email**: Create an issue on GitHub or contact the repository owner [@SSDEVIL108](https://github.com/SSDEVIL108).
- Please include steps to reproduce the issue.
- Reports will be reviewed within 48 hours.
